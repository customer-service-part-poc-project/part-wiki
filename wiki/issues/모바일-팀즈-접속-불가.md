# 모바일 팀즈 접속 불가

2026-09-11(금)경부터 **모바일 팀즈 앱**이 로그인 후 접근을 거부하는 상태. 장애가 아니라 **의도된 차단**이다.

## 증상
| 화면 | 문구 |
|---|---|
| 팀즈 앱 | "유효한 자격 증명을 가져오지 못했습니다. 로그아웃 후 다른 계정을 사용하시겠습니까?" |
| Microsoft 로그인 | "지금은 액세스할 수 없습니다. 정상적으로 로그인되었지만 이 리소스에 액세스할 수 있는 기준을 충족하지 않습니다. 관리자가 제한하는 브라우저, 앱 또는 위치에서 로그인하는 것일 수도 있습니다." |

- 겪은 사람: [[이정은]], [[김동준]], [[이강민]] (지난주 금요일부터)
- PC 팀즈는 영향 없음 (파트방 대화상 언급 없음 — 추론)

## 원인 (담당자 확인, [[전승찬]] 2026-09-14 09:41)
- **모바일 팀즈는 원래 막혀 있어야 하는 게 맞다.** 그동안은 테스트 때문에 열어둔 것
- **다음 주(2026-09-21 주) 보안 심의**를 진행하면서 바로 오픈할 수도 있고, 결과를 보고 오픈할 수도 있다

## 대응
- 할 것 없음. 보안 심의 결과 대기
- 확인필요: 공식 오픈 일자. 오픈되면 이 페이지를 `superseded`로 바꾼다
