# 평생보장소득 보고 이력

[[평생보장소득]]의 컨셉이 보고를 거치며 어떻게 바뀌었는지 시간순으로 정리한다.
**이 과제에서 "왜 지금 이 모양인가"를 알려면 이 페이지를 본다.**

## 컨셉 변천 요약

| | 1차 (8/20) 이전 | 1차 보고 후 | 2차 (9/3) 보고 후 |
|---|---|---|---|
| 솔루션 | — | 상품 추천에 한정 | **플랜에 대한 솔루션 제공** |
| 시뮬레이터 | — | 있음 (고객이 직접 값 조정) | **없음** |
| 타겟 | 2030 + 4050 | 4050 중심으로 좁힘 | 메인 4050 / 서브 2030 |
| 표현 | 계산 결과 리포트 | 현재/플랜 구분 | 미래 월급명세서 · 카드 조립 UI |

> ⚠️ 시뮬레이터는 1차에 있다가 2차에서 빠졌다. 2026-09-11 [[이정은]]이 개발 스코프에
> 시뮬레이션이 들어간 것을 발견해 이 사실을 다시 확인했다. 결론: **보고는 2차 기준으로 가고,
> 상세 기획·구현 단계에서 시뮬레이터 도입을 다시 검토한다.** ([[이강민]]·[[이정은]] 합의)

## 1차 — 2026-08-20 부사장님 보고
참석: 이창희 부사장, 조정연 캡틴, 김상혁 차장, 박기우 팀장, 강정민 팀장, [[이강민]], [[이정은]]

**방향을 정한 피드백**
- **시뮬레이션 대신 플랜 제시.** 정교하게 설계하기엔 너무 복잡하다.
  노후생활비 200/300만원 플랜을 두고 고객이 선택 → 거꾸로 지금 뭘 해야 하는지 가이드
- **메인 타겟 확정: "4050세대가 쌓은 목돈을 평생 월급으로 전환하려는 사람"**
- 단독 서비스 형태이므로 솔루션이 핵심이 된다 (타사는 앱 안의 부가 기능)
- 미래/현재 구분 접근은 좋다. 주택연금화·주택 매도 등 자산 통합 연금 전환 안내도 좋다

**제기된 리스크**
- 한 번 설정한 뒤 다시 들어올 포인트가 없다 → 은퇴자금을 이미 충족한 사람에게
  은퇴시기 앞당기기·위험자산→안전자산 전환 같은 솔루션을 주면 리텐션에 도움

**던져진 아이디어**
- 컨셉 전환안: **"은퇴 후에도 당신이 받던 월급을 계속 받을 거야"** — 소득대체율이 핵심.
  고객이 월급을 입력하면 그 월급을 노후에도 받게 하는 솔루션. 소득 크레바스 구간 소구
- 타사는 세금·건보료를 빼고 산정한다. 고객은 "평생 순 300만원"을 궁금해한다
- ISA·부동산 같은 비연금 자산을 연금으로 전환하는 것이 차별점
- 정교함보다 굵직한 자산(연금·주택)만 관리해도 충분. 정교함이 필요한 고객은 상담사 연결

## 2차 — 2026-09-03 부문장님 보고
참석: 이창희 부사장, 조정연 캡틴, 강정민 팀장, [[이강민]], [[이정은]]

**확인된 방향**
- **현재/플랜 컨셉 좋다.** 현재에서 변화를 보여주는 것도 좋다. 정확도는 이후 디벨롭
- **마이데이터는 연금 계산이 정확하지 않다. 정확도를 높이면 그 자체가 차별화가 된다**
  → 국민연금 계산기 / 퇴직연금 계산기(시뮬레이션 비교적 가능) / **주택연금 계산기(거의 정확)**
  → 이 피드백이 [[주택연금]]·[[마이데이터-연금정보]] 리서치를 촉발했다

**던져진 아이디어**
- 젊은 층은 전부 가정값이 되니 **베스트/워스트 플랜**을 보여주면 어떨까
- 시그널 스노우볼이 절세라면 우리는 **'미래 월급'**으로 가자
- 목표 플랜이 너무 높으면 **목표 하향 자체가 솔루션**이 될 수 있다
  (300만원 → "지금은 우선 100만원 목표로 잡아보자")
- **현실 자각 장치가 필요하다.** 60세부터 95세까지 나눠 받으면 금액이 굉장히 적다
  → 국민연금의 중요성을 알려주면 좋겠다
- **역방향 제시**: "20대에 개인연금 30만원 드는 사람은 평균적으로 60대에 월 300만원 삶을 산다"
- **플랜 탭 카드 조립 UI**: 국민연금 카드, 퇴직연금 카드를 추가하면 내 예상 월급이 어떻게 변하는지

## 2차 보고 이후 팀 회의 (클로바 노트 정리)

보고 피드백과 별개로 파트 내부에서 나온 논의. 사업·규제 현실이 많이 나왔다.

| 주제 | 요지 |
|---|---|
| 상품 연결의 벽 | 자사 상품만 추천하면 공정성 위반. 유사 상품 3개 이상 노출 필요. 당사 상품만 연결하면 계열사 부당지원 이슈. 시그널플래너도 직접 연결을 못 하고 정보 제공만 한다 |
| 투자자문업 | 한화생명은 과거 기관경고로 신사업 진출이 제한된 이력이 있다. 자본시장법상 투자자문업 해당 여부가 핵심 쟁점. 당사 서비스에서 당사 상품을 연결하는 건 괜찮을 것 |
| 법무 검토 | 우리 몫이다. 검토 과정에서 100이 80으로, 70으로 깎일 것. 베스트 안을 정리해둬야 한다. 법무팀이 느리니 **LLM으로 검토 범위를 좁혀서 전달해야 빨라진다** |
| 사내 중복 | wp팀이 '큐브'라는 절세 관리 서비스를 기획 중 — 절세 영역은 겹칠 수 있다 |
| 타겟 좁히기 | 보편적 국민 대상이면 유사 서비스와 구분이 안 된다. 특정 층으로 좁게 가는 게 명확할 수 있다 |
| 시장 규모 | 시그널 스노우볼 다운로드 수가 천 단위. 노후 준비는 그 순간이 돼야 와닿는다 |
| 접근 전환 | 자산·소비 관리 액션이 되는 걸 우려. 차라리 "조금 줄이면 지금처럼 한 달에 영화 네 번 볼 수 있어" 식으로 재미있게 |
| 지출 절감 프레임 | 지출을 줄이는 방법이 소득을 늘리는 방법보다 많다. 지출 절감이 연금 가입 효과와 대등하다는 걸 보여주면 파급력이 있다 |
| 주택연금 | 소득이 정해진 상태에서 더 납입하라는 건 비현실적. 다른 자산으로 돌리는 걸 고려해야. 종신보험 사망보험금 유동화로도 연금 전환 가능 |
| 사업 지표 | 지금 기대할 수 있는 건 CO 예자율. 확인필요: 정의 |
| 변액저축 | 금융상품 대비 경쟁력이 떨어져 고민. 연금을 제대로 받으려면 초반 앱 홍보가 중요 |
