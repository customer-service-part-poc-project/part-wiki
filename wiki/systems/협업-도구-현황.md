# 협업 도구 현황

> ⚠️ 2026-09-15 기준 변경됨: 기존 "슬랙·팀즈·텔레그램·노션 4개 병행" → 현재 **슬랙 종료, 3개 체제** ([[2026-09-14-슬랙-proj-평생보장소득-종료전]])
> 9/11에 "슬랙→텔레그램 이전 추론은 틀렸다"고 정정했었는데, 결과적으로 **이전은 맞았고 시점이 9/15였다.**

## 슬랙 종료와 이관 (2026-09-14 지시, [[이강민]])
1. 9/15부터 슬랙 사용 중지
2. 슬랙에 공유했던 자료는 **모두 노션에 업로드**, 올린 사람은 `:complete:` 표시
3. 이후 자료는 **공유 당일 노션에 업로드**한다 — 채팅에 파일을 올리고 끝내지 않는다

확인필요: 이관 완료 여부. 슬랙 첨부 7종([[2026-08-24-슬랙-proj-평생보장소득]])이 노션에 다 올라갔는지.

## 노션 도입 논의 (2026-09-10~11)

**배경**: [[이정은]]이 공용계정을 만들고 "팀즈 vs 노션" 의견을 물었다.
노션을 생각한 이유는 **나중에 QA보드 자동화나 슬랙 알림 등에 Claude를 활용**하기 위해서.

**무료 플랜 제약** ([[전승찬]] 조사)
| 제약 | 내용 |
|---|---|
| 파일 업로드 | 1회당 **5MB** — 우회 불가 |
| 콘텐츠 조각 | **1,000개** 제한. 텍스트 한 줄 = 1조각, 이미지 1개 = 1조각, 표의 행 하나하나 = 1조각. 누적되므로 금방 소진 |
| 우회 | 팀원을 **'게스트' 권한**으로 추가하면 조각 제한 우회 가능 |
| 인원 | 게스트 포함 **최대 10명** |

**의견**
- [[전승찬]]: "무거운 파일은 업로드하지 말자는 기준이면 노션도 문제 없어 보인다"
- [[한정은]]: "팀즈는 큰 파일 올리는 용도로만 인식된다. 전반적인 관리까지 할 거면 노션이 좋겠다"
- **결론: 노션으로 간다.** 회의록 업로드 완료, 리서치 자료 업로드 요청 중

> 파트 인원이 10명이고 노션 무료 플랜 상한도 게스트 포함 10명이다. **여유가 없다.**
> 슬랙 자료가 전량 이관되면 **콘텐츠 조각 1,000개 제한**도 빨리 닿는다. → [[확인필요-목록]]

## 텔레그램의 제약
- 리액션 이모지가 유료, 완료 표시 기능이 없다 ("슬랙이 그립네요", 9/11)
- 그래서 완료 표시는 노션의 `:complete:` 같은 다른 수단에 기댄다 — 추론
