# 협업 도구 현황

[[고객서비스파트]]가 쓰는 도구. **2026년 9월 현재 4개를 병행하고 있다.**

| 도구 | 용도 | 개설 | 비고 |
|---|---|---|---|
| **슬랙** | 과제별 채널 (`proj-평생보장소득`) | 2026-08-24, [[이강민]] | 워크스페이스 `한화생명 COE부문` |
| **팀즈** | 파트 방, 대용량 파일, [[주간업무-작성]] 문서(SharePoint) | 2026-09-10, [[이강민]] | "큰 파일 올리는 용도로만 인식된다" ([[한정은]]) |
| **[[텔레그램-파트방]]** | 파트 상시 소통, [[근태-공유]] | 2026-09-10, [[이강민]] | 10명 |
| **노션** | 파트 문서·회의록·리서치 아카이브 | 2026-09-10경, [[이정은]] | 고객서비스파트 공용계정 |

## 노션 도입 논의 (2026-09-10~11)

**배경**: [[이정은]]이 공용계정을 만들고 "팀즈 vs 노션" 의견을 물었다.
노션을 생각한 이유는 **나중에 QA보드 자동화나 슬랙 알림 등에 Claude를 활용**하기 위해서.

**무료 플랜 제약** ([[전승찬]] 조사)
| 제약 | 내용 |
|---|---|
| 파일 업로드 | 1회당 **5MB** — 우회 불가 |
| 콘텐츠 조각 | **1,000개** 제한. 텍스트 한 줄 = 1조각, 이미지 1개 = 1조각, 표의 행 하나하나 = 1조각. 누적되므로 금방 소진 |
| 우회 | 팀원을 **'게스트' 권한**으로 추가하면 조각 제한 우회 가능 |
| 인원 | 게스트 포함 **최대 10명** |

**의견**
- [[전승찬]]: "무거운 파일은 업로드하지 말자는 기준이면 노션도 문제 없어 보인다"
- [[한정은]]: "팀즈는 큰 파일 올리는 용도로만 인식된다. 전반적인 관리까지 할 거면 노션이 좋겠다"
- **결론: 노션으로 간다.** 회의록 업로드 완료, 리서치 자료 업로드 요청 중

> 파트 인원이 10명이고 노션 무료 플랜 상한도 게스트 포함 10명이다. **여유가 없다.**
> 인원이 늘거나 외부 협업이 생기면 바로 걸린다. → [[확인필요-목록]]

## 도구가 4개인 상태
현재 소통 채널이 슬랙·팀즈·텔레그램으로 셋, 문서가 노션·팀즈(SharePoint)로 둘이다.
확인필요: 각 도구의 역할 경계가 합의된 것인지, 정리 계획이 있는지.
