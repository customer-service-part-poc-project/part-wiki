# 파트 AI위키

[[고객서비스파트]]의 대화·회의·문서를 LLM이 읽고 정리해 두는 **세컨드 브레인**. 이 저장소 자체다.
구축·운영: [[김동준]]. 2026-09-11 15:22 파트방에 처음 공개됐다.

## 구성
| 산출물 | 무엇 | 공개 범위 |
|---|---|---|
| **위키** (`wiki/`) | 사람·조직·과제·도메인·결정을 위키링크로 엮은 지식 페이지. LLM이 유일한 저자 | 저장소(public) |
| **[[프로필-사이트]]** | 말투 신호로 만든 파트원 카드. GitHub Pages | 웹 공개 |
| **모바일 질의** | Claude 앱에서 위키에 질문 ("차주 파트 일정 알려줘" → 근태·루틴·진행 과제 표) | 구축자 시연 |

동작 원리는 `CLAUDE.md`(운영 규약)와 `llm-wiki.md`(원 패턴)에 있다.
원본(`raw/`)은 사람이 넣고, 위키(`wiki/`)는 LLM이 쓴다. 질문할 때마다 원문을 뒤지지 않고 **들어올 때 미리 녹여 둔다.**
