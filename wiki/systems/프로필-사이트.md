# 프로필 사이트

파트원 프로필을 GitHub Pages 로 공개하는 사이트. 위키와 **별개의 산출물**이다.

- 주소: `https://customer-service-part-poc-project.github.io/part-wiki/`
- 소스: `data/profiles/*.json` · 빌더: `scripts/build_site.py`
- 규약: `docs/PROFILE_SCHEMA.md` (스키마) · `docs/PRIVACY.md` (공개 범위)

## 무엇이 실리나
| 실린다 | 안 실린다 |
|---|---|
| 파트원 이름·직무 | 위키 본문 (`wiki/`) |
| 집계된 말투 신호 (건수·비율) | 원본 대화 (`raw/`) |
| 업무 성향 5축과 강점 | 임원·타부서 이름 |
| 재미 코너 (MBTI·나이대·혈액형·별명) | 사내 URL·문서 링크 |
| **대화 요청 가이드** | 발화 원문 인용 |

**화이트리스트 방식이다.** `data/profiles/` 에 있는 것만 나간다.
빌드가 금지 패턴을 검사해 걸리면 그 파일만 건너뛴다.

## 파이프라인
```
raw/ 대화 → extract_signals.py → data/signals.json
                                       ↓ (사람이 해석해 작성)
                              data/profiles/{이름}.json
                                       ↓
                              build_site.py → _site/
```
[[협업-도구-현황]] 의 슬랙·텔레그램 원문이 입력이다.

## 자동 갱신
`.github/workflows/pages.yml` 이 **매일 09:00 KST** 에 돈다.
신호를 재생성하고, 실제로 바뀌었을 때만 커밋한 뒤 사이트를 다시 배포한다.
`raw/` `data/` `scripts/` 가 push 될 때도 배포된다.

## 읽을 때 주의
- **재미 코너는 추측이다.** MBTI·나이대는 근거 강도 `약함`, **혈액형은 `없음(무작위)`**
- 업무 성향만 관측된 행동에 근거한다. **인사 평가나 줄세우기에 쓰지 않는다**
- 표본이 슬랙·텔레그램 2~3주치뿐이다. 발화 1~2건인 사람에겐 경고 배지가 붙는다
- 빠지고 싶으면 본인 JSON 의 `fun` 을 `null` 로 두면 재미 코너만 빠진다
