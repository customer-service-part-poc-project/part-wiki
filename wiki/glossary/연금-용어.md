# 연금 용어

[[평생보장소득]] 논의에 나오는 연금 용어. **모르는 단어가 나오면 여기부터 본다.**

## 연금 3층 구조
PRD 페르소나 카피의 뼈대다. "1층·2층은 자동으로 쌓이니 3층만 채우면 된다"는 프레이밍.

| 층 | 이름 | 성격 |
|---|---|---|
| **1층** | 국민연금 | 공적연금. 직장가입자는 자동, **지역가입자는 본인이 직접 신고해야 시작된다** |
| **2층** | 퇴직연금 (DB/DC/IRP) | 회사가 적립. 자영업자는 없음 |
| **3층** | 개인연금 (연금저축, IRP) | 본인 재량. **서비스가 개입할 수 있는 유일한 층** |

ISA는 엄밀히 3층이 아니지만, 만기자금을 연금계좌로 전환하면 3층을 채우는 재원이 되므로
PRD는 **"3층 전 단계 대기실"**로 포지셔닝했다.

## 퇴직연금 유형
| 용어 | 뜻 | 마이데이터 수신 |
|---|---|---|
| **DB형** (확정급여형) | 회사가 운용 책임, 퇴직 시 정해진 급여 | ⚠️ **보유 여부(Y/N)만 온다. 적립금도 없음** |
| **DC형** (확정기여형) | 회사가 납입, 근로자가 운용 | 잔액·평가금액·납입원금·개시예정일 |
| **IRP** (개인형 퇴직연금) | 개인이 여는 퇴직연금 계좌. 퇴직금 이전처 | 잔액·평가금액·납입원금·개시예정일 |

→ 상세: [[마이데이터-연금정보]]

## 계좌·상품
| 용어 | 뜻 |
|---|---|
| **연금저축** | 3층 세제적격 상품. IRP와 합산 900만원 세액공제 |
| **ISA** | 개인종합자산관리계좌. 연 2,000만원 한도. 만기자금을 연금계좌로 전환 시 추가 세액공제 |
| **TDF** (Target Date Fund) | 은퇴 목표연도(빈티지, 예: 2055형)에 맞춰 자동으로 위험자산 비중을 줄여가는 펀드 |
| **70% 룰** | 퇴직연금 계좌의 위험자산 최대 70%·안전자산 30% 의무. **적격 TDF는 예외로 94%까지** |
| **즉시연금보험** | 목돈을 일시납하고 바로 연금을 받는 생보사 상품. 1억원 이하·10년 이상 유지 시 이자소득세 비과세. **자사 크로스셀 지점** |
| **[[주택연금]]** | 집을 담보로 평생 월 지급받는 HF 보증 제도. 회계상으로는 역모기지(대출) |

## 개념
| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|
| **소득 크레바스** | 은퇴 시작 ~ 국민연금 개시 사이의 **소득 공백 구간** | 50대 페르소나의 가장 현실적인 공포. "몇 년 몇 개월간 월 얼마가 빈다"를 구체 수치로 보여주는 것이 핵심 UX |
| **소득대체율** | 은퇴 전 소득 대비 연금 수령액 비율 | "모든 연금은 소득대체율이 가장 중요" (부사장). **2026 개혁으로 43%** |
| **연기연금 / 조기연금** | 국민연금 수령 시점 조정. 연기 연 +7.2%(최대 5년 36%), 조기 연 −6% | 크레바스 대응 카드. 손익분기가 갈려 **일괄 추천 불가, 시뮬레이션으로 제시** |
| **연소자 기준** | [[주택연금]]에서 부부 중 **나이가 젊은 쪽** 기준으로 월지급금 산정 | 나이차가 크면 월지급금이 절반까지 줄어든다. 오해가 가장 잦은 지점 |
| **비소구** | 받은 돈이 집값을 넘어도 상속인에게 청구하지 않음 | 주택연금의 핵심 안전장치 |
| **과세이연** | 퇴직금을 IRP로 이전 시 퇴직소득세를 나중으로 미루는 것 | 나눠 받을수록 감면율이 커진다 (11년차부터 40% 감면) |

## 서비스 용어 (평생보장소득)
| 용어 | 뜻 |
|---|---|
| **목표** | 사용자가 정한 은퇴 나이 + 월 생활비 |
| **플랜** | 목표를 위한 항목별 배분 (사용자) |
| **솔루션** | 서비스가 제안하는 행동 — 증액·가입·연금화 |
| **인출 / 수령 계획** | 은퇴 후 자산을 어떻게 나눠 받을지. MVP 2차 |
| **노란우산공제** | 소기업·소상공인 공제. 퇴직연금이 없는 자영업자의 2층 대체재 |

## 데이터·제도
| 용어 | 뜻 |
|---|---|
| **마이데이터** | 본인신용정보관리업. 흩어진 금융정보를 한곳에 모아 조회 |
| **전송요구권** | 본인이 자기 정보를 보내달라고 요구할 권리. **본인만 행사 가능** → 배우자 대리 수집 불가 (신용정보법 33조의2) |
| **[[통합연금포털]]** | 금융감독원 연금 통합조회. **외부 API 없음**, 3영업일 지연. 쿠콘 경유로 확보 |
| **쿠콘** | 마이데이터 중계·스크래핑 벤더. **계약 예정.** 국민연금 예상액도 여기서 |
| **코드F (CODEF)** | 시그널플래너가 쓰는 스크래핑 벤더. 우리의 쿠콘에 해당 |
| **스크래핑** | 사용자 인증으로 기관 화면을 대신 읽어오는 방식. 마이데이터 API가 없는 국민연금은 이 경로뿐 |
| **HF** | 한국주택금융공사. [[주택연금]] 운영 주체 |
| **금융규제 샌드박스** | 혁신금융서비스 특례 제도. **규제신속확인**으로 당국에 공식 질의 가능 → [[규제-법무-검토항목]] |
