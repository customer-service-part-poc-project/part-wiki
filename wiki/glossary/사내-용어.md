# 사내 용어

[[고객서비스파트]] 안팎에서 쓰는 줄임말과 내부 표현. **뜻을 모르면 여기를 본다.**

## 조직
| 용어 | 뜻 | 확인 |
|---|---|---|
| **COE부문** | 슬랙 워크스페이스 이름. 파트가 속한 상위 부문 | 확인필요: 정식 명칭 |
| **디프팀** | 디지털프로덕트팀. 파트의 상위 팀 | |
| **COE Agile** | 지원 조직. 법무·준법 검토처럼 파트가 감당하기 어려운 일에 **지원 요청**할 수 있다 | 확인필요: 정확한 역할과 요청 절차 |
| **wp팀** | '큐브'(절세 관리 서비스)를 기획 중인 사내 팀 | 확인필요: 정식 명칭 |
| **캡틴** | 팀장과 부사장 사이의 직책 (조정연) | 확인필요 |

## 직무 표기
슬랙 표기는 `이름 (직무, 팀, 시차)` 형식이다. 예: `이강민 (UXM, 디프팀, 시차B)`

| 표기 | 추정 | 해당자 |
|---|---|---|
| **UXM** | UX 매니저 — 기획 | [[이강민]], [[이정은]] |
| **UXD** | UX 디자이너 | [[한정은]] |
| **BE / FE** | 백엔드 / 프론트엔드 | [[김동준]] / [[전승찬]], [[박정훈]] |
| **Android** | 안드로이드 개발 | [[한민우]] |
| **시차B / 시차C** | 시차출퇴근제 유형 | 확인필요: 실제 시간대 |
