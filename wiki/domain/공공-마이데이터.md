# 공공 마이데이터

행정·공공기관이 가진 본인 정보를 본인 동의로 받아오는 경로. [[평생보장소득]]에서 **금융 마이데이터가 못 주는 주택연금·국민연금 정보**를 채울 후보다.
조사: [[한민우]] (2026-09-15 스크럼, 출처 조사 단계).

## 확인된 것
| 항목 | 내용 |
|---|---|
| 제공처 | 정부24 |
| 승인처 | 행정안전부 |
| 담긴 정보 | [[주택연금]] 정보, 국민연금 정보 등 **항목이 많다.** 금융 마이데이터 + 공공 마이데이터만으로 필요한 정보 대부분을 얻을 수 있어 보인다 |
| 구조 | 승인을 받고 API로 조회하는 방식으로 보인다 (상세 미확인) |
| 조건 | **이용 목적이 구체적이어야 한다.** 예: 보험 심사, 보험금 지급 조회 |

## 걸림돌 — 목적 승인
우리의 목적은 "은퇴 솔루션 제안"이다. 행안부가 이 목적을 인정해 줄지가 관건.
- [[한민우]]: "그들을 설득할 수 있을지. 그것만 된다면 어떻게든 할 수 있다"
- [[이강민]]: 국가기관이니 공공 목적 달성 수준으로 프로그램을 짜야 할 것. 오픈 API가 아니라 승인 방식

→ 법무·행정 검토 항목으로 등록 ([[규제-법무-검토항목]] #14)

## 다른 경로와의 관계
| 정보 | 경로 후보 |
|---|---|
| 국민연금 예상액 | 쿠콘 스크래핑 (확정 방향) / 공공 마이데이터 (후보) → [[마이데이터-연금정보]] |
| 주택연금 | HF API(주택가격 입력) / 공공 마이데이터 (후보) → [[주택연금]] |
| 금융자산·연금계좌 | 금융 마이데이터 (제휴사 경유) → [[은퇴설계-데이터-출처]] |

## 확인필요
- 실제 제공 항목 목록과 API 구조, 승인 절차·기간
- 보험사가 "솔루션 제안" 목적으로 승인받은 선례가 있는지
- 금융 마이데이터 제휴사와 공공 마이데이터를 한 흐름에서 쓸 수 있는지
