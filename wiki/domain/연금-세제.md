# 연금 세제

[[평생보장소득]]의 솔루션 제안이 딛고 있는 세제 규칙. 페르소나별 배분 로직의 근거다.

> ⚠️ **아래 수치는 대부분 매년 조정된다.** 서비스에는 고정값이 아니라
> **연도 버전 정책 테이블**로 넣고 주기적으로 갱신해야 한다. ([[김동준]] 제안)

## 배분 우선순위 원칙
PRD가 세 페르소나 모두에 공통 적용하는 순서:

**① 세액공제 한도(연금저축 + IRP 합산 900만원) → ② ISA 한도(연 2,000만원) → ③ 나머지 목적자금**

이유: **세액공제는 투자수익률과 무관하게 확정되는 이득**이라 항상 최우선.

## 적립 단계
| 항목 | 한도·규칙 |
|---|---|
| 세액공제 | 연금저축 + IRP **합산 900만원** |
| ISA | 연 2,000만원 (서민형 요건 시 비과세 400만원) |
| ISA 만기 → 연금계좌 전환 | 전환금액의 10%, **최대 300만원 추가 세액공제** (60일 이내 전환 조건) |
| 국민연금 지역가입자 | 보험료 **9% 전액 본인 부담**. 연말정산 자동반영 없음 — 종합소득세 신고 시 직접 |

## 운용 단계 — 70% 룰
- IRP·연금저축 등 퇴직연금 계좌는 원칙적으로 **위험자산 최대 70% / 안전자산 30%** 의무
- **적격 TDF는 예외** — 위험자산 비중을 최대 94%까지 가능.
  은퇴 목표연도 빈티지(예: 2055형)를 고르면 은퇴가 가까워질수록 자동으로 안전자산 비중이 늘어난다

## 수령 단계
| 항목 | 규칙 |
|---|---|
| 퇴직금 → IRP 이전 | 퇴직소득세 **과세이연**. 연금수령 1~10년차는 이연퇴직소득세의 70%만(30% 감면), **11년차부터 60%만(40% 감면)** — 오래 나눠 받을수록 유리 |
| 사적연금 종합과세 | 합산 수령액 **연 1,500만원 초과 시 종합과세** (또는 16.5% 분리과세 선택). 수령 시기·금액을 분산해 1,500만원 밑으로 맞추는 전략이 유리한 경우가 많음 |
| 연금소득세율 | 연령별 차등 |
| 건강보험료 | 공적연금 50% 반영 / 피부양자 기준 2,000만원 |

## 국민연금 개시 시점 조정
| 옵션 | 효과 |
|---|---|
| 조기연금 | 연 **6% 감액** |
| 연기연금 | 연 **7.2% 증액** (월 0.6%), 최대 5년 연기 시 **36% 증액** |

- 소득 크레바스를 메우는 재료이자 역산 가이드의 변수
- ⚠️ **기대수명에 따라 유불리가 갈리는 손익분기 영역이라 일괄 추천이 아니라 시뮬레이션으로 제시해야 한다**

## 주택연금 관련 세제
→ [[주택연금]] (재산세 25% 감면, 이자비용 소득공제 200만원, 등록면허세 50% 감면, 소득 미산입)

## 서비스 반영 시 주의
- **PRD 현재 계산 로직은 세금·건보료를 반영하지 않는다** (오픈 이슈)
- 그런데 1차 보고에서 "고객들은 **평생 순 300만원**을 궁금해한다"는 지적이 나왔다.
  타사도 세금·건보료를 빼고 산정하지 않으므로 여기가 차별화 지점이 될 수 있다
- 세후 규칙 엔진을 **연도 버전 정책 테이블**로 설계할 것 ([[김동준]])

## 확인필요
- 2026년 기준 연령별 연금소득세율 실제 값
- 2026 국민연금 개혁(소득대체율 43%)의 계산 반영 방식
