# 키워드 검색 조사

1차 보고(8/20) TODO였던 "연령/성별에 따른 은퇴 키워드 검색비율 조사"의 결과. [[이강민]]·[[박정훈]], 네이버 통합검색 기준.
2차 보고(9/3) 자료에 포함됐다.

## 결과
| 발견 | 함의 |
|---|---|
| **모바일이 PC 대비 3~5배** | 모바일 우선 설계 (PRD와 일치) |
| 막연한 개념("은퇴 설계")보다 **상품 단위**(세액공제·연말정산)로 검색 | 유입 키워드를 상품 단위로 잡아야 한다 |
| **여성이 남성보다 많이 검색** — FIRE를 제외한 전 키워드 | 여성 맞춤 컨셉·디폴트 설계 검토. **"여성 타겟으로 메인을 잡다"**는 발언의 근거 |
| 타겟 연령대(4050)에서 연금 계열 검색 활발 | 타겟 설정이 검색 행동과 맞는다 |
| 40대에서 "퇴직"은 적지만 연금저축·퇴직금 등 **대체 키워드**는 많다 | 관심이 준 게 아니라 다른 말로 검색한다 |
| **30대와 50대의 키워드 검색량이 비슷하다** | 30대는 서브 타겟인데 니즈가 상당하다 |

## 도출된 방향
- **30대 = 동기 부여**, **40대 = 실행 계획 제안**에 포커스
- 여성 사용자를 기본 가정으로 둘지 검토 — 가계 경제권을 쥔 쪽이 엄마인 경우가 많고 노후 고민도 더 한다는 관찰과 맞물린다

## 월별 트렌드 (구글 트렌드, 2026-09-15 스크럼)
[[이강민]]이 연금 관련 상위 검색어로 확인. "미정님"(확인필요 — [[김민지]]?)도 앞서 검색했다고 언급.

| 시기 | 검색량 |
|---|---|
| 연초 | 조금 많다 (연말 상승이 이어진 것) |
| 4월 ~ 10월 | 거의 없다 |
| **11월 ~ 12월** | **급상승** |

→ 마케팅은 11월(길게 10~12월) 집중, 출시는 그 2~3개월 전 → [[출시-시점-검토]] ([[2026-09-15-스크럼-클로바노트]])
확인필요: 원본 그래프, 키워드 목록, 조사 기간

## 해석 시 주의
- 추론: "남성이 검색을 덜 한다"가 "준비를 잘해서"인지 "관심이 없어서"인지는 모른다. 회의에서도 농담조로만 언급됐다
- 확인필요: 조사 기간, 원본 수치·그래프. 보고서에 쓰려면 근거 자료가 필요하다
