# 통합연금포털

금융감독원이 운영하는 연금 통합조회 서비스. [[평생보장소득]]의 데이터 확보 경로 후보.

담당: [[한민우]] (검토 분담 2번)

> **2026-09-11 갱신**: 경로가 정해졌다. **쿠콘 경유.** 쿠콘이 국민연금 + 통합연금포털에서 가져온다고 안내한다.
> 마이데이터 사업자를 직접 취득하는 안은 기간 문제로 빠졌다. 상세 스펙은 계약 후 명세 확인 필요.

## 초안 검토 (김동준)
| 항목 | 내용 |
|---|---|
| 외부 API | **없음** |
| 대안 1 | 위임 로그인(스크래핑) — 교보 방식. **→ 쿠콘 벤더 경유로 채택 방향** |
| 대안 2 | 사용자 직접 입력/캡처 |
| 걸림돌 | 스크래핑이 **마이데이터 사업자 스크래핑 제한(신용정보법 22조의9)**에 저촉되는지 준법 검토 필요. 교보는 어떤 근거로 하는지 확인 |
| 지연 | **3영업일 지연** |

## 권장 구조
> 즉시 결과(자체 계산) → 포털 값 도착 시 보정 — **2단계 구조**

3영업일 지연을 그대로 UX에 노출하면 이탈한다. 먼저 우리 계산으로 결과를 주고 나중에 정밀도를 올린다.

## 확인필요
- [[한민우]]의 조사 결과
- 교보생명이 위임 로그인을 하는 법적 근거
- 마이데이터 사업자의 스크래핑 제한 저촉 여부 (법무)
