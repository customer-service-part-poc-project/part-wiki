# 주택연금

집을 담보로 맡기고 **내 집에 계속 살면서 평생 매월 연금을 받는** 국가 보증 제도.
[[평생보장소득]]에서 "부동산을 연금으로 전환"하는 핵심 수단이다.

- 정리: [[한민우]] (주택연금 리서치 / 주담대 보유 케이스), [[김동준]] (연동 검토 + 왕초보 마인드맵)
- 기준: 한국주택금융공사(HF) 공식 자료, **2026-03-01 계리모형 개편 반영**

> 2차 보고에서 "주택연금 계산기는 거의 정확하게 계산 가능"이라는 피드백이 나와
> 정확도 차별화의 우선 후보가 됐다. → [[평생보장소득-보고-이력]]

## 제도의 정체 — 연금이 아니라 대출이다
이름은 '연금'이지만 **회계상 역모기지(대출)**다. 매월 돈을 받고, 이자와 보증료가 잔액에 쌓이고, 사후에 집을 팔아 정산한다.

| 구조 | 내용 |
|---|---|
| 소유권 | 그대로 유지. 공사는 근저당권 또는 신탁 우선수익권만 취득 |
| 이자 | 현금으로 내지 않음. 부부 모두 사망 시 정산 |
| 비소구 | 받은 돈이 집값을 초과해도 상속인에게 청구하지 않음. 남으면 상속인에게 |

정산 금액 = 월지급금 누계 + 수시인출금 + 보증료(초기 1.0% + 연 0.95%) + 이들에 대한 대출이자

## 가입 대상
| 항목 | 내용 |
|---|---|
| 연령 | 부부 중 1명이 **55세 이상** |
| 주택 보유 | 부부 기준 **공시가격 12억원 이하** |
| 대상 주택 | 주택법상 주택, 신고된 노인복지주택, 주거목적 오피스텔 |
| 거주 | 가입자 또는 배우자가 실제 거주(주민등록 전입) |

### ⚠️ 서비스 구현 시 가장 중요한 두 가지

**1. 12억은 '공시가격', 실제 받는 금액은 '시세' 기준**
- 가입 자격 판단 → 공시가격 12억 이하
- 월지급금 산정 → 공사 인정 **시세** (부동산원 → KB → 공시가격 → 감정평가 순)
- 공시가격이 시세의 70% 전후라 **시세 16~17억 집도 가입 대상**에 들어온다
- → **공시가격 API만 붙이면 월지급금이 과소 산출된다.** 시세 확보 경로가 진짜 검토 과제

**2. 부부는 '연소자' 기준**
연령은 부부 중 **나이가 젊은 쪽** 기준. 종신 지급이라 "몇 년치를 내줘야 하는가"를 정하는 건 오래 살 쪽이기 때문.

5억 아파트, 남편 70세 고정:

| 아내 나이 | 적용 연령 | 월지급금 |
|---|---|---|
| 70세 (동갑) | 70세 | 153만 9천원 |
| 60세 | 60세 | 105만 3천원 |
| 55세 | 55세 | **78만원** |

- 손해가 아니라 **교환**이다 — 월 현금흐름을 내주고 보장 기간을 산 것.
  아내가 100세까지 살면 45년 × 78만원 = 약 4억 2,100만원으로 역전된다
- 나이차가 크면 주택연금은 연금이 아니라 **장수보험**에 가깝다
- **'기다리는 전략'이 무력화된다**: 남편이 80세가 돼도 아내가 65세면 126만 4천원.
  10년을 기다려도 동갑 부부가 70세에 받는 153만 9천원에 못 미친다
- 사별·이혼으로 단독 세대가 되면 본인 나이로 다시 계산된다 → **처음부터 재검토 필요**

## 월지급금표 (일반주택 · 종신지급 · 정액형, 2026.3.1 기준)
부부 중 연소자 연령 기준 (천원/월)

| 연령 | 1억 | 3억 | 5억 | 7억 | 9억 | 12억 |
|---|---|---|---|---|---|---|
| 55세 | 156 | 468 | 780 | 1,092 | 1,404 | 1,872 |
| 60세 | 210 | 632 | 1,053 | 1,475 | 1,896 | 2,528 |
| 65세 | 252 | 758 | 1,264 | 1,770 | 2,276 | 3,035 |
| 70세 | 307 | 923 | 1,539 | 2,155 | 2,770 | 3,414 |
| 75세 | 381 | 1,143 | 1,906 | 2,669 | 3,431 | 3,666 |
| 80세 | 483 | 1,449 | 2,416 | 3,382 | 4,060 | 4,060 |

- **한도 구간 주의**: 75세 11억·12억이 모두 366만 6천원, 80세 9억 이상이 모두 406만원.
  고가주택일수록 담보 대비 효율이 급락한다
- 주택 유형별 (70세·3억): 일반주택 92.3만원 = 100% / 노인복지주택 78.9만원 = 85% / 오피스텔 74.6만원 = 81%
- 연령 민감도: 5억 기준 55세 78만 → 80세 242만. **3배 이상.** 이 기울기가 의사결정의 대부분을 지배한다

## 지급방식·유형
- 방식 7종: 종신지급 / 종신혼합 / 확정기간혼합 / 대출상환 / 대출상환우대 / 우대지급 / 우대혼합
- 유형 3종: **정액형**(매월 동일) / **초기증액형**(초기 3·5·7·10년 더 받고 이후 70% 수준) / **정기증가형**(3년마다 4.5% 증가)
  - 정기증가형은 구매력 하락을 방어하는 유일한 선택지지만 연 1.5% 수준이라 물가를 다 따라잡진 못한다

## 장점
평생 거주 + 평생 지급(장수 리스크를 공사가 인수) / 비소구 / 집값 하락 방어(정액형은 불변) /
현금 이자 부담 없음 / 재산세 25% 감면·이자비용 소득공제 200만원 한도·등록면허세 50% 감면(2028 일몰) /
**월지급금은 대출이라 소득에 안 잡힘 → 기초연금 수급에 불이익 없고 오히려 유리** /
주택연금 지킴이 통장 월 250만원까지 압류 방지 / 이사 시 담보주택 변경 승계 가능

## 단점
가입 후 집값 상승이 월지급금에 반영 안 됨(**상승분은 소멸이 아니라 상속인에게 감**) /
정액형 명목 고정 — 물가 2%면 20년 후 실질 구매력 약 67% / 이자·보증료가 복리로 잔액 증식 /
해지 비가역성(3년 재가입 제한, 초기보증료 일부만 환급) / 조기 사망 시 효율 낮음 /
거주 구속(부부 모두 1년 이상 미거주 시 종료) / 12억 상한·월지급금 한도 / 금리 민감

## 시나리오별 유불리

**집값 전망**: 하락 → 매우 유리(공사에 풋옵션을 산 셈) / 횡보 → 유리(설계 기준) / 상승 → 불리

실제 데이터도 이를 뒷받침한다. 서울 신규 가입은 2023년 3,849건 → 2025년 2,830건(−20.5%)으로 2020년 이후 최저,
비수도권은 2025년 5,732건(+6.0%)으로 증가. **집값이 오를 지역일수록 가입 유인이 떨어진다.**

**주택가격대**
- 2.5억 미만 + 기초연금 수급권자 → **우대형, 가장 유리** (일반형 대비 최대 20~25% 더 수령, 감정평가수수료 지원)
- 3~6억 → 표준 구간 (평균 가입자가 72세·4억원)
- 7~12억 → 애매. 회수율 하락 + 한도 도달. 매각 후 다운사이징과 비교 필요
- 공시가 12억 초과 → 불가

**보유 주택 수**: 1주택이 가장 유리(실거주 예외·재산세 감면 모두 1주택 한정).
2주택 합산 12억 초과는 3년 내 처분 조건 — **미이행 시 받은 연금 전액을 이자와 함께 상환.**

**가입 연령**: 55~60세 조기 가입은 신중해야 한다. 5억 기준 월 78만원으로는 생활비가 안 되면서
향후 25년간 더 유리한 조건으로 갈아탈 길을 스스로 좁힌다. 55세 가입의 합리적 용도는
종신 연금이 아니라 **종신혼합방식으로 목돈을 인출해 부채를 정리**하는 쪽에 가깝다.

## 종료·제한
- 종료: 부부 모두 사망 / 주민등록 이전 / 1년 이상 미거주 / 소유권 상실 / 처분조건 미이행
- **이용 도중 이혼·재혼한 배우자는 받을 수 없다.** 가입 시점의 배우자만 승계 대상
- 세대이음 주택연금: 가입자 사망 후 55세 이상 자녀가 동일 주택으로 가입 가능 (근저당권방식 한정)
- 수령 중 주택 추가 취득 → **일반형은 제한 없음**, 우대형은 1주택 제한·연 1회 검증·6개월 내 미처분 시 감액(소급 환수 아님, 처분하면 회복)

## 개발 연동
- HF 오픈API **"주택연금 예상월지급금 조회"** 존재: 주택가격·소유자 만나이·배우자 만나이 → 지급방식별 월지급금·인출한도
- 입력이 **주소가 아니라 주택가격** → 주소→시세 변환은 우리 몫 (MVP는 사용자 입력)
- 월지급금은 매년 재산정 → **유효기간 표시 필요**

## 확인필요
- 초기보증료 환급 기간이 2026년 개편으로 3년 → 5년 연장됐다는 정보가 있으나 공사 공식 페이지 재확인 필요
- 주담대가 남은 주택의 가입 가능 여부 — [[한민우]]가 별도 문서로 정리. 원본 확보 필요
