# 경쟁·벤치마크 서비스

[[평생보장소득]] 논의에서 언급된 외부·사내 서비스를 한곳에 모은다.
**[[이강민]]이 맡은 3차 보고서의 "서비스 포지셔닝" 항목 재료다.**

## 시장 인식 한 줄
> 교보생명·모니모·토스뱅크·우리은행 등 대부분은 **마이데이터 자산관리의 부가 기능**으로만 은퇴설계를 제공한다.
> 부부 합산 가정 단위 설계나 부동산 포함 통합 설계를 하는 곳은 드물다. ([[평생보장소득-PRD]])

## 직접 경쟁

| 서비스 | 주체 | 포지션 | 우리와의 관계 |
|---|---|---|---|
| **시그널 스노우볼** | — | **절세**에 집중 | 가장 자주 비교되는 대상. "타사는 이렇게 넣으면 세금을 아낀다, 우리는 불확실한 미래를 보장한다"는 대립 구도로 잡았다. 다운로드 수는 **천 단위** — 시장이 아직 작다는 근거이자 리스크 |
| **시그널플래너** | — | 마이데이터 사업자 | 상품 연결을 직접 못 하고 **정보로만 제공**한다. 우리가 부딪힐 규제의 선례 → [[규제-법무-검토항목]] |
| 교보생명 | 교보생명 | 마이데이터 자산관리 부가 기능 | [[통합연금포털]]을 **위임 로그인(스크래핑)** 방식으로 붙인 것으로 보인다. 법적 근거 확인 필요 |
| 모니모 | 삼성생명 | 마이데이터 자산관리 부가 기능 | |
| 토스뱅크 | 토스 | 마이데이터 자산관리 부가 기능 | |
| 우리은행 | 우리은행 | 마이데이터 자산관리 부가 기능 | **부부 합산·통합 자산 설계를 부분적으로 제공하는 유일한 사례** |

## 벤치마크 (기능 참조)

| 서비스 | 참조 포인트 |
|---|---|
| **뱅크샐러드** | [[부부합산-마이데이터-제약]]의 구현 흐름 원본. 초대 → 배우자 각자 인증 → "우리 집 합계"만 노출·세부 비공개 → 일방적 연결 해제 가능. "가족 명의 자산은 법령상 직접연결 불가"를 명시적으로 공지한다 |
| **국민연금공단 노후준비서비스** | [[한민우]] 발견(2026-08-25). **로그인 없이** 간단재무설계·재무계산기(화폐시간가치, 예적금계산)를 제공한다. 진입장벽 없는 온보딩의 참고 사례 |

## 사내

| 서비스 | 주체 | 이슈 |
|---|---|---|
| **큐브** | wp팀 | **절세 관리 서비스**를 기획 중. 우리가 절세 영역으로 확장하면 겹친다. 확인필요: 영역 조정이 필요한지 |

## 우리의 차별 주장
| 축 | 근거 |
|---|---|
| 단독 서비스 | 타사는 자산관리 앱 안의 부가 기능. 그래서 우리는 솔루션이 핵심이 돼야 한다 (부사장, 8/20) |
| 연금 계산 정확도 | 마이데이터는 예상수령액을 주지 않는다. 계산기 3종(국민연금·퇴직연금·[[주택연금]])으로 정확도를 높이면 그 자체가 차별화 (부문장, 9/3) |
| 부부 합산 가정 단위 | 우리은행 정도만 부분 제공 |
| 부동산 포함 통합 설계 | 40~50대 자산의 약 73%가 부동산 |
| 세후 기준 제시 | 타사는 세금·건보료를 빼고 산정하지 않는다. 고객은 "평생 순 300만원"을 궁금해한다 |
| 미래 월급 프레임 | 절세(타사) vs 미래 보장(우리) |

## 확인필요
- 시그널 스노우볼·시그널플래너의 운영 주체
- 각 서비스의 실제 기능 범위 — **직접 써보고 정리한 자료가 아직 없다**
- 큐브와의 영역 중복 여부
- 국내외 유사 서비스 추가 조사 (해외 사례 언급이 없다)
