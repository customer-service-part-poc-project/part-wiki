# 텔레그램 이름 표기

텔레그램에서 한국 이름이 뒤집혀 보이는 문제와, 파트가 합의한 해결 방식.
[[김동준]]이 2026-09-09 [[텔레그램-우리팀]] 방에 제안했다. 👍6 ❤1 로 호응이 가장 컸던 메시지다.

## 문제
텔레그램은 이름을 **`[First Name]` + `[Last Name]` 순**으로 조합해 보여준다.
성을 Last Name 칸에 넣으면 "홍길동"이 **"길동 홍"** 으로 뒤집힌다. **앱 설정으로는 해결되지 않는다.**

실제로 이렇게 보이고 있다.

| 텔레그램 표시 | 실제 |
|---|---|
| `선영 나` | [[나선영]] |
| `정훈 박` | [[박정훈]] |
| `Minwoo Han` | [[한민우]] |
| `정은 한화생명 이` | [[이정은]] |

## 해결
```
설정 → 프로필 편집
  이름(First Name) 칸에  →  성+이름을 한 번에 입력 (예: 홍길동)
  성(Last Name) 칸은     →  비워 두기
```

필수는 아니다. 다만 방 안에서 이름이 통일되면 서로 찾기 편하다는 것이 제안 취지다.

## 위키 도구와의 관계
이 문제 때문에 수집 도구가 **표시 이름을 정규 이름으로 되돌리는 표**를 들고 있다
(`scripts/extract_signals.py` 의 별명 표). 파트원이 표기를 바꾸면 그 표도 같이 손봐야 한다.
안 고치면 그 사람의 발화가 신호 집계에서 통째로 빠진다. → [[프로필-사이트]]
