# 백신접종 예약

사내 백신 예방접종을 **H-CORE**에서 직접 예약하는 절차. [[한정은]]이 2026-09-14 파트방에 공유했다.

| 항목 | 내용 |
|---|---|
| 예약 시작 | 2026-09-14(월)부터 |
| 접종 가능일 | **2026-10-19 이후** 날짜 선택 |
| 시스템 | H-CORE → [[사내-용어]] |

## 경로
```
H-CORE > 언더라이팅 > 종합건강진단 > 백신접종 > 백신접종예약
  > 주민번호 입력 > 일자 선택 (10.19~) > 클레버스 비밀번호 입력 후 저장
```

- 확인필요: 어떤 백신인지(독감 추정), 비용 부담, 접종 장소
- 확인필요: '클레버스'가 무엇인지 (사내 인증 시스템으로 추정) → [[사내-용어]]
