# 고객서비스파트

한화생명 **COE부문 디지털프로덕트팀(디프팀)** 산하 파트. 이 위키의 주체.

> 추론: 슬랙 워크스페이스가 `한화생명 COE부문`이고 전원의 표기가 `디프팀`인데,
> 팀즈·노션·텔레그램의 공용 공간은 모두 `고객서비스파트` 이름을 쓴다.
> 따라서 **COE부문 > 디지털프로덕트팀 > 고객서비스파트** 구조로 판단했다. 확인필요.

## 구성원

전원 디지털프로덕트팀 소속. 괄호는 슬랙 표기(직무, 팀, 시차출퇴근 유형).

| 이름 | 직무 | 시차 | 역할 |
|---|---|---|---|
| [[이강민]] | UXM | B | 과제 총괄, 보고, 주간업무 관리 — 추론: 파트 리더 |
| [[이정은]] | UXM | C | 기획, [[평생보장소득-PRD]] 작성·관리 |
| [[한정은]] | UXD | B | 디자인, 페르소나 시나리오 지원 |
| [[김동준]] | BE | B | 백엔드. 기술 타당성 검토, [[주택연금]] 담당. [[파트-AI위키]] 구축. 세일즈 오퍼링 주간 미팅 참석(겸무 추론) |
| [[한민우]] | Android | B | 안드로이드. 개발 스코프 작성, [[통합연금포털]] 담당 |
| [[전승찬]] | FE | — | 프론트엔드. [[부부합산-마이데이터-제약]] 담당. **MSP 과제 지원 (10월 말까지)** |

| [[나선영]] | 확인필요 | | [[Direct-변액저축보험]] 담당. 변액협의체회의 참석. 텔레그램 표기 `선영 나` |
| [[이혜진]] | 확인필요 | | [[Direct-변액저축보험]] 담당. 파트 주간회의 변액 대표 |

- `UXM` = UX 매니저(기획), `UXD` = UX 디자이너로 추정. 확인필요
- `시차B` `시차C` = 시차출퇴근제 유형. **시차C는 늦게까지 근무하는 쪽** — [[이정은]]이 "18시 이후에도 응답" 관찰에 "시차 C라서"라고 답했다 ([[2026-09-15-텔레그램-파트방-9월-2주차]]). 구체적 시간대 확인필요
- [[텔레그램-파트방]] 인원 **10명 전원 확인** (2026-09-15). 위 표가 전체 명단이다

## 특이 사항
- **파트원이 다른 과제를 겸한다.** [[전승찬]]은 MSP 과제(10월 말까지), [[김동준]]은 세일즈 오퍼링. 스크럼 시간이 그에 맞춰 움직인다 → [[정기-회의]]
- **현업부서가 없는 상태로 과제를 진행 중이다.** 법무·준법 검토를 파트가 직접 수행해야 한다
  (필요 시 COE Agile 지원 요청). → [[규제-법무-검토항목]]
- 팀장 발언: **"이 멤버는 사업화를 위한 최소 인원."** 잘 되면 추가 지원. 연금 솔루션 전문성은 사내 자산관리 인력(상속연구소·WM)이나 외부 컨설팅으로
- 팀장 스타일: 정리된 보고서보다 **중간중간 계속 보자**는 쪽
- LLM(Claude, Gemini)을 리서치·검토·문서 작성에 적극 활용한다.
  법무 검토도 "LLM으로 범위를 좁혀서 전달해야 빨라진다"는 인식을 공유한다.
