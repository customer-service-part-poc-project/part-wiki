- **원본**: `raw/meetings/2026-09-파트회의-클로바노트-3세션.md`

## 세션 1 — 인출 시뮬레이터 · 솔루션 범위 · 회원가입

**논점**: 인출(수령 계획) 시뮬레이터를 MVP에 넣을 것인가.

| 입장 | 요지 |
|---|---|
| 전승찬 | MVP 향하는 단계. 메인 기능보다 **어펜딕스로 두고** 운영해보며 50대 반응이 좋으면 그때 꺼내자 |
| 이정은 | 솔루션 = 디테일의 모음. 프리셋에서 값을 바꿔보려면 디테일이 있어야 한다. **수령 그래프 모양은 4개 정도**(앞을 두텁게·평평하게·크레바스 먼저 막고 낮게 등) — 모양을 보여주고 고르게 하면 쉽다 |
| 이강민 | 솔루션 3개를 먼저 제시하고 다 마음에 안 들면 자유도를 연다. **초장부터 "알아서 시뮬레이션하세요"는 아니다** |
| 개발 | 대표 케이스 조합으로 솔루션처럼 보여주기 / AI 추천·설계를 옆에 인사이트로 띄우기(구현이 제일 쉽다) |

**결정**
- 인출은 **포함하되 MVP 1차에서는 제외, 2차**. 사업계획·컨셉 보고에는 큰 그림을 담고 "세부 계획은 쪼개서 간다"고 말한다
- 담지 않으면 "이게 끝이구나"로 읽힐 위험이 있어 큰 그림에는 넣는다
- 타겟이 4050이라 적립 쪽이 먼저. 수령 가이드는 "추가될 예정"으로 1차에 예고

**주택연금 입력**: 마이데이터에 집 주소가 없다. **집값·다주택 여부는 수동 입력**. 시세·공시가 체크리스트가 필요하다 → [[주택연금]]

**회원가입**: 시그널 스노우볼은 소셜 로그인. 우리도 카카오·애플 소셜로 가능한지 검토. 금융 서비스라 제약이 있을지 확인 → [[평생보장소득-개발범위]]

**팀장 스타일**: 보고서 정리본 말고 **중간중간 계속 보자**고 한다.

## 세션 2 — 법무 검토 요청 · 진행 상황 · 페르소나

### 법무 검토 요청 준비 (이강민)
- "연금저축 25만원"보다 "**한화투자증권 IRP 25만원 가입**"으로 즉시 안내하는 게 명확하고 유리한데, **투자자문·권유 권한이 없다**. 풀 방안과 표기 방법을 단계별로 확인
- **모니모 구조**: 통합 분석 화면 + 삼성생명·화재·카드 **회사별 탭**. 추천하는 회사가 개발·운영해야 하는 구조로 보인다. 우리도 따라야 하는지, 한화생명 통합 플랜 화면에서 계열사 상품을 통합 제안할 수 있는지, 어렵다면 회피 방안
- Claude로 확인한 기준이라 확실하지 않음을 밝히고, 더 좋은 방안 제안을 요청하는 취지
- 텍스트만으로는 그림이 안 그려지니 **프로토타입을 함께 첨부**
- 오늘 내로 요청. 사업계획 초안은 텍스트로 먼저 채우고 팀장 확인 후 PPT
→ [[규제-법무-검토항목]]

### 데이터 원천 (개발)
- **쿠콘과 계약 예정** (담당: 정미님). 마이데이터 사업자 자체 취득은 기간이 걸려 경우의 수에서 빠짐 → 정리가 깔끔해졌다
- 쿠콘 API 문서는 PDF·웹 소개 수준. 국민연금 + 통합연금포털에서 가져온다고만 돼 있다. 가져올 수 있다고 판단하고 개발 검토 정리 중

### 국민연금 예상액 — 가져올 수 있다 (전승찬)
> ⚠️ 이 발견이 [[마이데이터-연금정보]]의 "예상수령액은 어디서도 안 온다"를 뒤집는다.

- 마이데이터 API로는 국민연금이 안 온다. 그러나 **벤더 스크래핑**으로 가져온다
- 시그널플래너도 마이데이터 사업자지만 국민연금은 **코드F**(헤비팩토리 산하 벤더)가 스크래핑. 서비스 내 인증 → 인증 데이터를 코드F에 전달 → 공단 로그인과 동일한 결과를 API로
- **쿠콘도 같은 솔루션을 갖고 있다.** 우리가 따로 계산할 필요 없이 통으로 받는다
- 항목(알려진 것): 예상 연금액, 총 예상 가입기간, 수령 시작 연월, 기본 연금액, 지급률, 총 예상 납부 보험료. **실제 스펙은 명세를 봐야 안다**
- ⚠️ 마이데이터 사용 중 스크래핑을 겸하는 것 — 금융사 다 하지만 **법무 검토를 받는 게 안전**

### 국민연금 변수 (개발, 은영님과 논의)
- 조기/연기·납입 기간에 따라 금액이 달라지는데, 이걸 바꿔보려면 **평균 소득 등 추가 변수**가 필요(가입증명 서류에 있음)
- **이정은 결정: 일단 종신·65세 수령 고정값** → 포털 월 예상 수령액만으로 충족
- 나중에 디벨롭하려면 수기 입력을 받거나, 안 받으면 고정값만 보게 하는 식으로 유연하게

### 페르소나 (이정은, 한정은과 정리)
| 페르소나 | 단계 | 솔루션 |
|---|---|---|
| 30대 회사원 | 적립·실행 | 세제혜택 상품. "아직 어리니 소액으로 충분" |
| 40대 자영업자 | 적립 | 노란우산공제 + IRP·연금저축 + ETF 장기투자 |
| 40대 주부 | ? | 국민연금 임의가입(9만원) + 배우자 연동 — **솔루션이 사실상 없다** |
| 50대 회사원 | 수령 앞둠 | 자산의 연금화 — 즉시연금보험·주택연금·IRP 종신형 |

**고민 1 — 주부를 넣을 것인가**: 소득이 없으면 은퇴설계 자체가 성립하기 어렵다. 솔루션이 "배우자 연동하세요"뿐이라 이상하다.
- 이강민이 주부를 넣은 이유: 퇴직연금 없는 케이스 + 가계 경제권은 엄마인 경우가 많고 노후 고민도 엄마가 더 한다
- 전승찬: **부부 전용 서비스가 아니다. 대전제는 개인, 부부는 부가.** 싱글 자영업자도 있다
- 개발: 온보딩에 "연동 안 하고 샘플로 보기" 옵션을 두면 커버된다
- 이강민: **주부가 꼭 아니어도 된다.** 부부 연동을 자연스럽게 풀 타겟이 필요했던 것
- 이강민: "**저희가 여성 타겟으로 메인을 잡다 보니까**" — 키워드 검색 결과(여성 > 남성)가 배경

**고민 2 — 적립기 솔루션이 비슷하다**: 30대든 40대든 "IRP·3층 채우고 남으면 ETF·변액"이 일반적. 차별점은 40대의 목돈·교육비 정도. 50대는 수령 계획이라 아예 다르다 → **앱 범위를 수령 계획까지 넓힐 것인가** (원래 기획은 "은퇴 전까지 잘 준비해봐"였다)

### ⚠️ 솔루션 전문성 이슈 (전승찬 제기)
- 이 서비스는 솔루션이 핵심인데, **솔루션을 우리가 정한다.** 연금 전문가도 아니고 근거도 빈약하다. 뻔한 답만 나올 것
- 선택지 10개의 경우의 수로 솔루션 몇 벌을 우리가 정하는 건 **위험**하다. 전문가가 필요하다
- 이강민: 지금은 "이렇게 될 수 있다"는 **예시**. 사업화되면 지원 요청 — 그래서 사업계획서에 **협조 필요 사항**을 넣는다. 팀장이 "이 멤버는 사업화 최소 인원"이라 했다
- 사내 자산관리 인력(상속연구소, WM 사업부)이 있는 것 같다. 지원받으려면 부회장·사장 선의 지시가 필요. 안 되면 외부 컨설팅
- 이정은: "자산관리사도 아닌데 이걸 내야 하나" 같은 고민. 지금은 보고서상 디테일 수준을 보여주는 것

## 세션 3 — PRD 2차 시안 설명 · 키워드 검색 (보고 당일)

### 구조 변경 (이강민)
- **4탭(현재·미래·플랜·마이) → 3탭(현재·플랜·마이)**. 미래와 플랜이 너무 겹쳤다 — 미래에서 부족을 보고 플랜을 바꾸고 다시 미래로 가는 왕복이 생겼다. 미래 예측과 솔루션을 함께 제시하는 게 효과적
- 5대 기능 중 "시뮬레이션을 통한 정교화 설계" → "**솔루션을 통한 신속한 설계**"
- **용어 정리** (파트 안에서도 혼선이 있었다):

| 용어 | 뜻 | 누가 |
|---|---|---|
| **목표** | 몇 세에 은퇴, 월 얼마 | 사용자가 설정 |
| **플랜** | 목표를 위해 하고 있거나 설정한 배분 (ISA·IRP·연금저축·저축) | 사용자 |
| **솔루션** | "ISA 10만원 증액", "한화생명 연금저축 25만원 가입" | **서비스가 제안** |

- 현재 탭 = 현재 총자산 + 목표 대비 달성. 플랜 탭 = **메인 탭**. 미래 목표를 위한 플랜 + 솔루션. 현재 상황은 미포함

### 화면 상세 (이정은)
- 온보딩: 은퇴 계획 설정 화면 추가. 자녀 유무·결혼 여부 대신 **라이프스타일 카드** 선택 → 플랜 선택("여유로운 노후 월 300만원")
- 플랜 탭: "이대로라면 월 50만원 부족 · 목표의 83% · 은퇴 가능 65세(목표보다 5살 더)". 항목별 솔루션 — 개인연금 늘리면 +4만원, IRP 가입, 부동산 입력했으면 주택연금 전환 시 +얼마. 하단 연령별 예상 월 소득 그래프
- **유사 이용자 인사이트**: 한화생명 상품만 추천하는 느낌 대신 "은퇴 준비 잘 된 비슷한 이용자는 이렇게 저축한다 → 너는 평균보다 덜 하니 더 해봐"
- 마이 탭: 목표 수정(90세 고정 곱해 필요 자금). 게이미피케이션 — 배우자 자산·실물 금·미술품 등을 미션처럼 하나씩 업데이트

### 키워드 검색 조사 (이강민·박정훈, 네이버)
→ [[키워드-검색-조사]]

### 여유층 솔루션 (개발 제기)
- 지금은 **부족한 사람 플랜만 있다.** 많이 넣고 있는 사람 = 더 공격적으로 넣을 수 있는 사람 = **우리 이익**. 그들을 위한 솔루션도 필요
- 이강민: 300 목표인데 500 가능하면 → 은퇴 시기 당기기, 또는 "조금만 더 저축하면 해외여행 월 1회" 식으로 생활수준 상향 유도. **충분하다고 냅두면 만족은 해도 앱을 안 쓴다**
