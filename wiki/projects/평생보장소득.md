# 평생 보장소득 은퇴설계 플랫폼

[[고객서비스파트]]의 주력 과제. 내부 코드명 **PLUS**(개발 문서 기준).
사업계획서 제목은 **"평생보장월급 플랫폼"** (2026-09-14 초안 파일명. 추론: 서비스명 후보 → [[사내-용어]]).
이 페이지가 과제의 허브다.

> **한 줄 정의**: 부부 합산 자산과 부동산까지 아우르는 통합 설계로 개인의 목표 연금 수령액을 계산하고,
> 재정 상황과 선호 생활수준에 맞춘 솔루션으로 은퇴 준비에 대한 확신을 주는 플랫폼.

## 핵심 컨셉

**"은퇴 후에도 당신이 받던 월급을 계속 받게 한다."**

정교한 시뮬레이션 대신 **플랜 선택 → 역산 가이드** 구조를 택했다.
고객이 노후 생활비 플랜(예: 월 200/300만원)을 고르면, 거꾸로 지금 무엇을 해야 하는지를 제시한다.

| 축 | 내용 |
|---|---|
| 메인 타겟 | **4050세대 중 쌓아둔 목돈을 평생 월급으로 전환하려는 사람** — 키워드 조사 후 **여성을 기본 가정**으로 두는 방향 검토 중 → [[키워드-검색-조사]] |
| 확장 타겟 | 2030세대 (습관 형성·장기 계획) |
| 차별점 1 | 부부 합산 가정 단위 설계 |
| 차별점 2 | 부동산 등 실물자산 포함 통합 설계 (40~50대 자산의 약 73%) |
| 차별점 3 | 연금 계산 정확도 — 마이데이터가 못 주는 예상수령액을 직접 계산 |
| 포지션 | 자산관리 앱의 부가 기능이 아닌 **단독 서비스** |

경쟁 프레임: 타사(시그널 스노우볼 등)가 "이렇게 넣으면 세금을 아낄 수 있어"라면,
이 서비스는 **"불확실한 미래를 이렇게 보장해"**로 간다.

## 정보구조 — 3탭

핵심 원칙은 **"사실"과 "계획"을 절대 섞지 않는 것**.

| 탭 | 성격 | 내용 |
|---|---|---|
| 현재 | 사실 (마이데이터로 확인된 것만) | 준비율 %, 순자산, 목표 자금, D-day, 자산구성 |
| 플랜 | 조건부 ("이 계획대로라면") | 항목별 계획 금액, 충족/부족, 추천 솔루션, 소득 계단 그래프 |
| 마이 | 설정 | 은퇴 목표, 부부합산 연동, 게이미피케이션 |

플랜 탭에서 세운 계획은 실제로 실행되어 **마이데이터를 거쳐서만** 현재 탭에 반영된다.
→ 상세는 [[평생보장소득-PRD]]
