## 근거로 쓰인 시장 수치
| 지표 | 값 |
|---|---|
| 4050세대 중 "준비 부족" 응답 | 45% |
| 노후 적정 생활비 (부부) | 월 298~350만원 |
| 적정 생활비 대비 부족액 | 월 약 120만원 |
| 희망 은퇴 나이 vs 실제 | 65세 vs 56세 (9년 차이) |
| 준비 필요성을 느끼는 순간 1위 | "예상 연금수령액을 조회했을 때" 30.3% |
| 40~50대 자산 중 부동산 비중 | 약 73% |

> 확인필요: 각 수치의 출처(조사기관·연도). 보고서에 쓰려면 근거가 필요하다.

## 경쟁 인식
교보생명·모니모(삼성생명)·토스뱅크·우리은행 등은 **마이데이터 자산관리의 부가 기능**으로만 은퇴설계를 제공한다.
부부 합산 가정 단위 설계나 부동산 포함 통합 설계를 하는 곳은 드물다 (우리은행이 부분적).

## 페르소나 3종

세 페르소나 모두 **① 세액공제 한도(연금저축+IRP 합산 900만원) → ② ISA 한도(연 2,000만원) → ③ 나머지** 순서를
배분 원칙으로 공유한다. 세액공제는 수익률과 무관하게 확정되는 이득이라 항상 최우선. → [[연금-세제]]

### ① 계획 실행형 — 30대 남성 회사원
- Pain: 은퇴까지 남은 시간이 길어 막연함
- 카피: **"국민연금·퇴직연금(1층·2층)은 회사 다니는 한 자동으로 쌓여요. 당신이 할 일은 3층만 채우는 것."**
- 설계 의도: 1층·2층은 "자동" 고정 표시로 안심시키고, IRP·연금저축·ISA만 재량 영역으로 시각 분리
- 배분 예시 (월 200만원 여력): IRP 25만 / 연금저축 50만 / ISA·변액·ETF 125만
- 상품 톤: 적극투자형. 적격 TDF는 퇴직연금 70% 룰의 예외로 위험자산 94%까지 가능
- ⚠️ 규제: 특정 펀드명 직접 추천은 투자자문업 이슈. **카테고리 추천까지만**, 상품 매칭은 별도 화면으로 분리

### ② 맞벌이 유형 — 40대 여성 자영업자
- Pain: 2층 퇴직연금 없음. 내 계좌만 보면 부부 준비 상태를 판단할 수 없음
- 카피: **"회사원은 국민연금이 자동으로 쌓이지만, 당신은 당신이 먼저 움직여야 시작돼요."**
- 핵심: 국민연금 지역가입자는 본인이 직접 신고해야 시작된다 (직원 없어도 소득 있으면 의무대상).
  보험료 9% 전액 본인 부담. 연말정산 자동반영 없어 종합소득세 때 직접 챙겨야 함
- 마이데이터로 잡히는 게 거의 없어 **본인 입력값 의존** → [[마이데이터-연금정보]]
- 설계 의도: 부부합산 토글을 켜면 개인 기준으로 부족해 보이던 준비율이 가구 기준으로 크게 개선되는 경험
- 세액공제 한도가 남은 배우자 계좌로 저축여력을 돌리는 것이 가구 전체로는 유리

### ③ 목돈 전환형 — 50대 남성 회사원
- Pain: 목돈을 평생월급으로 바꾸는 방법을 모름. **소득 크레바스가 현실적 공포**
- 카피: **"퇴직금을 한 번에 받으면 거기서 끝이지만, 나눠 받으면 평생 월급이 됩니다."**
- 핵심 UX: 크레바스를 막연한 불안이 아니라 "몇 년 몇 개월간 월 얼마가 빈다"는 구체 수치로
- 절세 전략: 퇴직금→IRP 이전 / 국민연금 연기연금 / ISA 만기→연금계좌 전환 / 1,500만원 분산 → [[연금-세제]]
- 상품: IRP 종신형 · **즉시연금보험(자사 생보 상품 크로스셀 지점)** · [[주택연금]]

## 계산 로직 (개념)
| 항목 | 방식 |
|---|---|
| 은퇴생활기간 | 희망 은퇴 나이 ~ **90세** 가정 |
| 현재 값 | 마이데이터로 확인된 실제 자산만. 자기선언 불가 |
| 준비율 | 목표 월생활비를 총자산으로 환산한 "필요 은퇴자금" vs 현재 총자산 |
| 플랜 충족 | (실제 자산 + 계획 항목 기대 기여분) vs 목표. 열 때마다 재계산, 저장값 없음 |
| 소득 계단 그래프 | 종신형 소득은 개시 연령부터 동일. 금융자산은 총액 ÷ 은퇴생활기간 균등분할 |
- 별도 확률 시뮬레이션 없음. 준비율 %를 성공 가능성 지표로 사용
- **세금·건강보험료는 이번 계산에 반영하지 않음** (오픈 이슈)

## 오픈 이슈 (PRD 12장)
- 추천 항목별 마이데이터 감지 가능 여부 실사 (주택연금 전환·자산 증여는 확인 필요)
- 본인 입력(미확인) 항목의 재확인 넛지 주기·UX
- 90세보다 오래 생존할 경우의 리스크 안내 방법
- 플랜 탭 계획 금액의 초기값 채우기 방식
- 국민연금 외 고정(비편집) 처리 항목 (예: DB형 퇴직연금)
- **목표 월생활비 → 필요 은퇴자금 환산식 확정 (할인율, 은퇴기간)**
- 현재 탭 인사이트 피드 도입 여부
- "설정하기" 버튼이 실행 완료로 오인되지 않도록 카피 설계
- 세금·건보료 반영 여부 / 소득대체율 프레임 채택 여부
