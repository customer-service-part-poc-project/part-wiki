# 공개 범위 · 마스킹 · 재미 코너 취급

`../members/docs/PRIVACY.md` 의 규칙을 이 저장소에 맞게 이식했다.

---

## ⚠️ 가장 중요한 전제

**이 저장소는 public 이다. 확인됨 (2026-09-11).**

```
visibility: public · has_pages: true
https://github.com/customer-service-part-poc-project/part-wiki
```

인증 없이 `wiki/` 내용이 조회된다. 파트에서 이를 인지하고 공개로 두기로 했다.
**그래서 아래 두 가지가 더 중요해진다.**

1. 이 사이트는 위키 본문을 내보내지 않는다 (화이트리스트)
2. 위키에 새 내용을 넣을 때 **공개를 전제로** 쓴다

그런데 이 위키에는 공개되면 곤란한 것이 많다.

| 위키에 있는 것 | Pages 공개 시 |
|---|---|
| 사내 조직도·보고 라인 (임원 실명 포함) | ❌ 나가면 안 된다 |
| 과제 전략·경쟁 분석·법무 검토 항목 | ❌ 나가면 안 된다 |
| SharePoint · 구글문서 · 노션 링크 | ❌ 나가면 안 된다 |
| 파트원 실명과 직무 | ⚠️ 파트 내 공유 전제 |

**그래서 이 사이트는 위키 전문을 내보내지 않는다.**
`data/profiles/*.json` 의 **멤버 프로필**과 `data/projects/*.json` 의 **프로젝트 요약**만 빌드 대상이다.
화이트리스트 방식이다. 프로젝트 요약은 위키를 읽고 사람이 다시 쓴 것이지, 위키 본문의 복사가 아니다.

`wiki/` · `raw/` 는 빌드 입력이 아니며 `_site/` 에 복사되지 않는다.

---

## Pages 에 나가는 것 / 안 나가는 것

**나가는 것**
- 파트원 이름 · 직무 · 파트명
- 집계된 말투 신호 (건수·비율. **원문 인용 아님**)
- 업무 성향 5축과 강점
- 재미 코너 (MBTI · 나이대 · 말투 뱃지 · 받은 반응 · 별명 · 대화 가이드)
- 프로젝트 요약 (과제명 · 상태 · 마일스톤 · 영역별 현황 · 담당 · 다음 단계) — `docs/PROJECT_SCHEMA.md`

**안 나가는 것**
- 위키 본문 전체 (`wiki/`)
- 원본 대화 (`raw/`)
- 임원·타부서 인물 이름
- 사내 URL · 문서 링크
- 발화 원문 인용
- 법무 검토 **항목** · 경쟁 분석 · 시장 수치 · 벤더 이름 (프로젝트 카드에서도 뺀다. 상태만 적는다)

## 빌드가 거부하는 금지 패턴

`scripts/build_site.py` 가 프로필·프로젝트 JSON 전체를 문자열로 훑어 아래를 찾으면 **그 파일을 건너뛴다.**

| 분류 | 패턴 |
|---|---|
| 사내 URL | `sharepoint.com` · `hanwhalifem365` · `docs.google.com` · `notion.com` · `app.notion` |
| 임원·타부서 실명 | `이창희` · `조정연` · `강정민` · `박기우` · `김상혁` |
| 연락처 | 전화번호 · 이메일 · 주민번호 형태 |
| 원문 인용 | `samples_` · `raw_quote` · `quotes` 키 |
| 성별 추정 | `gender` · `성별` 키 — **신호가 거의 없고 틀리면 어색해진다. 아예 넣지 않는다** |

임원 실명을 막는 이유: **파트원이 아니고 본인 동의도 없다.** 파트 재미 코너에 올릴 대상이 아니다.

| MBTI | **약함** |
| 나이대 | **약함** |
| ~~혈액형~~ | **2026-09-15 폐지.** 근거가 0인 값을 싣지 않기로 했다 |

`profile` 과 `fun` 을 섞어 읽으면 추측이 사실처럼 회람된다. **사이트에서 시각적으로 분리한다.**

## 표본이 작다는 사실을 숨기지 않는다

이 위키의 데이터는 슬랙·텔레그램 대화 **2~3주치**가 전부다.
발화가 1~2건뿐인 사람도 있다.

- `signals.confidence` 가 `낮음` 이면 **카드에 경고 배지를 띄운다**
- 데이터가 적은 사람의 프로필을 데이터가 많은 사람과 **같은 무게로 비교하지 않는다**

---

## 사람에 대해 쓸 때

- **호의적으로 쓴다.** 재미 코너는 놀리는 자리가 아니다
- 외모 · 성격 결함 · 업무 능력 비하로 읽힐 표현을 쓰지 않는다
- 성별을 추정하지 않는다
- 본인이 빼달라고 하면 **그 사람의 `fun` 블록을 `null` 로 만든다.** 사이트는 프로필만 표시한다

## public 전제에서 남은 위생 과제

저장소를 public 으로 두기로 한 이상, 위키 본문도 공개 문서다. 아래는 정리하면 좋은 항목이다.

| 항목 | 왜 | 상태 |
|---|---|---|
| **SharePoint 공유 링크의 토큰** (`?e=...`) | 링크를 아는 사람이 문서에 접근할 수 있다. 가장 실질적인 위험 | 미조치 |
| 구글 문서 · 노션 링크 | 권한 설정에 따라 접근 가능 | 미조치 |
| 임원·타부서 실명 | 본인 동의 없이 공개 문서에 실명이 남는다 | 미조치 (프로필 사이트에서는 차단됨) |
| 법무 검토 항목 · 과거 기관경고 이력 언급 | 회사 대외 리스크로 읽힐 수 있다 | 미조치 |

> 프로필 사이트(`_site/`)는 위 항목을 **빌드 단계에서 차단**한다.
> 위키 본문(`wiki/`)은 차단 대상이 아니므로, 필요하면 별도로 정리해야 한다.

이미 커밋된 내용은 git 히스토리에 남는다. 과거 커밋에서 지우려면 history rewrite 가 필요하다.
