# 은퇴설계 플랫폼 PRD
평생 보장 소득 플랫폼 · 프로토타입 개발 요구사항

이 문서는 은퇴설계 플랫폼 프로토타입 개발을 위한 제품 요구사항 문서입니다. 화면 구성/슬라이더 범위 등 세부 UI 스펙과 계산 수식은 이 문서에서 다루지 않으며, 별도 화면설계 문서 및 구현 과정에서 확정합니다.

## 0. 문서 정보
- 프로젝트명: 평생 보장 소득 플랫폼
- 배경: 생명보험사의 "평생 보장 소득" 전략과 연결된 은퇴설계 서비스. 기존 은퇴설계는 상품·수익률 중심으로 설명돼서 고객이 이해하기 어려움. "월소득을 평생 보장받는다"는 개념을 직관적으로 이해시키고, 저축·연금 추가납입 같은 실제 행동으로 이어지게 하는 것이 목표
- 참고 문서: DESIGN-figma.md

## 1. 문제 정의 및 기회
**시장 공백**
- 영유아~중년까지는 생애주기별 서비스가 촘촘한 반면, 노년기로 갈수록 서비스가 드물고 뚜렷한 시장 강자가 없음
- 은퇴 준비기(40~60대 초반)는 노후 준비가 절실하고 경제활동도 활발해 고객 가치가 큰데도, 이들을 체계적으로 준비시켜주는 대표 서비스가 없음

**고객 문제**
| 지표 | 내용 |
|---|---|
| 은퇴 준비 부족 체감 | 4050세대의 45%가 "준비가 부족하다"고 응답 |
| 노후 생활비 부족액 | 적정 생활비(부부 기준 월 298~350만원) 대비 월 약 120만원 부족 |
| 희망 대비 이른 은퇴 | 희망 은퇴 나이 65세, 실제 은퇴 나이 56세 — 9년 앞당겨짐 |
| 준비 필요성을 느끼는 순간 | "예상 연금수령액을 조회했을 때"가 30.3%로 가장 높음 |

**기존 서비스의 한계**
- 교보생명·모니모(삼성생명)·토스뱅크·우리은행 등 대부분 마이데이터 기반 "자산관리"의 부가 기능으로만 은퇴설계 제공
- 부부 합산 가정 단위 설계나 부동산까지 포함한 통합 자산 설계를 제공하는 곳은 드묾(우리은행 정도만 부분적으로 제공)

**기회**
- 부부 합산 기준 가정 단위 설계
- 40~50대 자산의 약 73%를 차지하는 부동산 등 실물자산까지 포함한 통합 설계
- 솔루션을 통한 신속한 설계

## 2. 프로덕트 컨셉
한 줄 정의: 부부 합산 자산과 부동산까지 아우르는 통합 설계로 개인의 목표 연금 수령액을 계산하고, 재정 상황과 선호 생활수준에 맞춘 솔루션으로 은퇴 준비에 대한 확신을 주는 플랫폼

| 기능 축 | 설명 |
|---|---|
| 목표 기준 설계 | 개인의 목표 연금 수령액을 기준으로 설계 |
| 부부 합산 설계 | 배우자 동의 하에 연금정보를 연동해 가정 단위로 종합 조회 |
| 위험방어 설계 | 라이프 이벤트(실직, 질병 등)에 대비한 안전 설계 |
| 통합 자산 설계 | 부동산 등 실물자산까지 포함해 설계 |
| 솔루션을 통한 신속한 설계 | 개인의 재정 상황과 선호 생활수준을 반영해 최적의 솔루션/플랜을 바로 제안 |

## 3. 타겟 사용자
- 메인 타겟: 4050세대 중 쌓아둔 목돈을 평생 월급으로 전환하려는 사람
- 확장 타겟: 20~30대, 습관 형성/장기 계획에 관심 있는 사람

아이디어 — 팀 회의
- 타겟층을 지금보다 더 좁혀야 할 수도 있음 — 30~50대를 모두 커버하려다 보니 솔루션이 보편적인 수준에 머무는 것 같음
- 다음 보고에서는 "고객 유형별 솔루션"을 더 구체화할 필요 — 연령·직업 등으로 고객 유형을 더 세분화해서(예: 30대 회사원, 40대 주부, 50대 자영업 등) 페르소나별 맞춤 솔루션으로 풀어야 구체적인 피드백과 진전이 있을 것

### 페르소나
우선순위는 항상 ① 세액공제 한도(연금저축+IRP 합산 900만원) → ② ISA 한도(연 2,000만원) → ③ 나머지 목적자금 순서. 세액공제는 투자수익률과 무관하게 확정되는 이득이라 항상 최우선이라는 원칙

**① 계획 실행형 — 30대 남성 · 회사원**
정규직, 국민연금+퇴직연금(DC/DB)이 자동으로 쌓이는 중
- Pain: 은퇴까지 남은 시간이 길어 막연함
- Needs: 노후 자금 확인 / 세제혜택 최적화(세액공제 합산 900만원 한도 점검) / 습관화(자동이체)
- UX Point: 진입장벽을 낮추고, 가볍게 현재 상황 진단, 저축 계획 제시
- Solution: "저축 계획 및 시작" — 세제혜택을 챙기면서 소액으로 빨리 시작하세요
- 카피: "국민연금·퇴직연금(1층·2층)은 회사 다니는 한 자동으로 쌓여요. 당신이 할 일은 3층(개인연금)만 채우는 것."
- 솔루션 매핑: 플랜 탭에서 국민연금·퇴직연금은 "자동 반영됨 ✓"으로 고정 표시하고, IRP·연금저축·ISA만 유저가 직접 채우는 재량 영역으로 시각적으로 분리. 재량 영역에는 ETF·변액보험 상품을 연계 추천
- 구체적 자산배분 예시 — 월 200만원 저축여력 가정: IRP 25만원(300만원/년, 세액공제 한도) / 연금저축 50만원(600만원/년, 합산 900만원 완성) / ISA·변액보험·ETF투자 125만원(1,500만원/년, ISA 연 2,000만원 한도 내)
- 솔루션 상품 — 적극투자형: IRP·연금저축 등 퇴직연금 계좌는 위험자산 최대 70%·안전자산 30% 의무("70% 룰"). 단 적격 TDF는 예외로 위험자산 최대 94%까지 가능. 은퇴 목표연도 빈티지(예: 2055형) 편입
- 규제 caveat: 특정 펀드명·상품을 직접 추천하면 투자자문업 라이선스 이슈. "적격 TDF 같은 유형을 찾아보세요" 수준의 카테고리 추천으로 설계하고, 실제 상품 매칭은 별도 제휴/판매 화면으로 분리

**② 맞벌이 유형 — 40대 자영업자 여성 · 맞벌이 부부**
국민연금은 지역가입자로 본인이 직접 신고해야 하고, 퇴직연금도 없어 개인 준비율은 낮은 편. 다만 배우자가 회사원
- Pain: 2층 퇴직연금 없음. 내 계좌만 보면 부부 은퇴 준비가 부족한 건지 판단이 안 됨
- Needs: 가구 단위 확인 / 세액공제 최적화(한도 남은 배우자 계좌 우선 배분)
- UX Point: 배우자 연동 유도하여 가구 합산 은퇴 준비율 표시
- Solution: "부부 합산 설계" — 개인만 보면 부족해도, 배우자와 합치면 이미 준비돼 있을 수 있어요
- 배경: 1층 국민연금이 지역가입자 미신고 상태로 방치돼 있거나 소득이 들쭉날쭉해 신고를 미뤄온 경우가 많음. 마이데이터로 잡히는 게 거의 없어 본인 입력값에 의존. 본인도 국민연금 가입 대상(직원 없어도 소득 있으면 지역가입자 의무대상)이라는 사실 자체를 모르는 경우가 많음
- 카피: "회사원은 국민연금이 자동으로 쌓이지만, 당신은 당신이 먼저 움직여야 시작돼요."
- 구체적 자산배분 예시 — 본인 명의, 월 100만원 저축여력: 국민연금 지역가입자 신고(보험료 9% 전액 본인 부담) / IRP 25만원 / 연금저축 50만원 / ISA·변액보험·ETF 25만원(+한도 남으면 배우자 계좌 우선 배분)
- 주의: 지역가입자 기준소득월액, 세액공제 한도 등은 매년 조정되는 수치. 고정값이 아니라 최신값 연동/주기적 업데이트 대상으로 설계할 것
- 부부합산 메커니즘: 배우자 연동(마이 탭, 동의 시 토글) — 국민연금은 배우자가 직장가입자여도 자동 커버되지 않음(건강보험 피부양자와 다름) / 세액공제 한도 배분 — 부부 각자 900만원 한도 중 남은 쪽으로 저축여력 우선 배정

**③ 목돈 전환형 — 50대 남성 · 회사원**
정년이 코앞. 퇴직금을 어떻게 굴릴지·국민연금 개시를 언제로 할지 등 실제 의사결정이 임박한 시기
- Pain: 목돈을 "평생월급"으로 바꾸는 구체적 방법을 모름. 국민연금 개시 전 공백구간이 현실적인 공포
- Needs: 의사결정 지원 / 소득 크레바스 해소 / 상향 탐색(은퇴 앞당기기)
- UX Point: 소득 공백을 보여주고, 행동 가능한 전략/상품까지 연결
- Solution: "자산의 연금화" — 은퇴생활에 적합하게 자산의 체질을 개선하세요
- 카피: "퇴직금을 한 번에 받으면 거기서 끝이지만, 나눠 받으면 평생 월급이 됩니다."
- 구체적 절세 전략 — 퇴직금 1억원 + 여유자금:
  - 퇴직금 → IRP 이전 필수: 퇴직소득세 과세이연. 연금수령 1~10년차 이연퇴직소득세의 70%만(30% 감면), 11년차부터 60%만(40% 감면)
  - 국민연금 연기연금: 1년 늦출 때마다 7.2% 가산(월 0.6%), 최대 5년 연기 시 36% 증액. 손익분기 계산 필요 — 일괄 추천이 아니라 시뮬레이션으로 제시
  - ISA 만기자금 → 연금계좌 전환: 전환금액의 10%, 최대 300만원 추가 세액공제 (60일 이내)
  - 사적연금 종합과세 기준: 합산 수령액 연 1,500만원 초과 시 종합과세(또는 16.5% 분리과세 선택) — 수령 시기·금액 분산 전략
- 솔루션 상품: IRP 종신형 연금개시 / 즉시연금보험(일시납, 1억원 이하·10년 이상 유지 시 이자소득세 비과세, 종신형 선택 시 평생 수령 — 자사 상품 크로스셀 지점) / 주택연금

## 6. 핵심 기능
### 6.1 정보구조 개요
서비스는 **현재 · 플랜 · 마이** 3개 탭으로 구성. 핵심은 "사실"과 "계획"을 절대 섞지 않는 것 — 현재 탭은 마이데이터로 확인된 실제 자산만 보여주고, 계획이 반영된 미래 전망은 전부 플랜 탭에서 조건부로만 다룸.

마이 탭의 목표가 현재 탭(준비율)과 플랜 탭(충족 여부) 계산의 기준이 되고, 플랜 탭에서 세운 계획이 실제로 실행되면 마이데이터를 거쳐서만 현재 탭에 반영됨.

| 탭 | 성격 | 주요 내용 |
|---|---|---|
| 현재 | 사실 — 지금 이 순간의 스냅샷 | 준비율(%), 순자산 총액, 목표 자금, D-day, 자산구성 도넛차트 |
| 플랜 | 조건부 시뮬레이션 — "이 계획대로라면" | 항목별 계획 금액, 충분/부족 계산, 부족 시 추천 상품, 소득 계단 그래프 |
| 마이 | 설정 | 은퇴 목표 조회/수정, 부부합산 연동, 게이미피케이션, 기타 설정 |

부부합산은 별도 탭이 아니라 현재 화면 안에서 "개인 / 가정 합산" 보기를 전환하는 방식으로 제공. "목표"(희망 은퇴 나이 + 노후생활 금액 프리셋)는 마이 탭에서, "계획"(목표를 채우기 위한 항목별 금액 배분)은 플랜 탭에서 각각 수정.

### 6.2 온보딩 — 목표 설정
- 나이/성별은 따로 입력받지 않고 회원가입 정보를 그대로 사용
- 희망 은퇴 나이 입력
- 라이프스타일 프리셋 선택 (자녀 있는 맞벌이 부부 / 자녀 없는 부부 / 1인 가구 / 자녀 독립 완료 부부)
- 라이프스타일에 맞는 노후생활 금액 플랜 선택 (예: 월 300만원 — 여유로운 노후생활)
- 선택 입력(건너뛰기 가능): 보유 자산/연금 정보
- 목표는 이후 마이 탭에서 언제든 다시 설정 가능

### 6.3 현재 탭
- 헤드라인은 "지금처럼 하면 월 얼마"류의 미래 전망이 아니라, 목표(필요 은퇴자금) 대비 현재 총자산을 비교한 **준비율(%)** — 예: "은퇴 준비율 76%". 계산은 마이데이터로 확인된 실제 자산만 기준
- 현재 순자산 총액 + 전월 대비 증감액, 은퇴 목표 자금(필요 총액), 은퇴까지 D-day
- 자산 구성 도넛차트 (부동산/연금/투자/현금 등 비중)
- 미래를 다루는 요소(소득 계단 그래프 등)는 이 탭에 두지 않음
- 플랜 대비 진척도: 항목별 납입 총액을 진행바로. 세부 내역까지 보여주는 일반 자산관리 앱과 달리 항목별 총액 수준으로만
- 검토 중: 매월 변화 인사이트 피드(예: "이번 분기 퇴직연금 수익률이 가정치보다 낮아 은퇴일이 밀렸습니다")

### 6.4 플랜 탭
- 상단에 현재 목표를 참고용으로 표시. 목표 자체 수정은 마이 탭
- 헤드라인은 "이 플랜대로라면" 노후생활비가 충분한지/부족한지. 예상 노후생활비, 목표금액 대비 %, 은퇴 가능 나이를 서브 지표로
- "내가 세운 은퇴 계획"을 항목별 월 납입 금액 리스트로 표시
- 계산 결과는 현재 탭의 실제 자산 + 계획 항목의 기대 기여분을 목표와 비교. 화면을 열 때마다 재계산, 저장 상태값 없음
- 부족하면 부족분을 메울 추천 상품/행동 노출(ISA 비중 증가, IRP 증액, 주택연금화, 연금보험 가입 등)
- 추천은 계획 리스트 안에 칩 형태로도 노출 — 탭하면 "설정하기" 버튼이 있는 모달로. "설정하기"는 계획 금액을 수정할 뿐 실행 완료를 뜻하지 않음
- 월별 납입 여부 체크리스트 기능은 넣지 않음

| 항목 | 편집 가능 여부 | 비고 |
|---|---|---|
| 국민연금 등 소득 기반 강제 납부 항목 | 고정 (편집 불가) | 현재 납입액 유지 가정 |
| 퇴직연금(DC), 개인연금·보험, 저축, 투자, IRP | 편집 가능 | 유저가 직접 금액 조정 |

- 화면 하단에 **소득 계단 그래프** — 연령별 예상 월 소득을 계단형으로. 국민연금 같은 종신형 소득과 금융자산(은퇴~90세 균등분할)을 쌓아서. 목표선 대비 어느 구간에 공백이 큰지, 특히 은퇴~국민연금 개시 전 "소득 크레바스" 구간을 한눈에

아이디어 — 팀 회의
- 미래 연금을 "미래 월급명세서" 형태로. 연령별 월급 타임라인(예: 60세 200만원 / 70세 300만원)
- 연금 필요성을 공감 못하는 고객이 많을 수 있음 — 근미래를 제시("지금 30만원을 안 내면 5년 후엔 60만원을 내야 한다")
- 회사원은 월급이 고정돼 추가 납입 결정이 어려움 — 지출을 줄이는 방향 메시지("OTT·외식을 몇만원 줄이면 미래에 연금을 20만원 더 받을 수 있다")

### 6.5 마이데이터로 확인 안 되는 항목 처리
- 주택연금 전환, 자산 증여 등 마이데이터로 확인 불가능한 항목은 유저 직접 입력 가능
- "확인됨(마이데이터)" 숫자와는 절대 섞지 않고 "본인 입력(미확인)"으로 항상 구분 표시
- 본인 입력 항목은 주기적 재확인 넛지 필요

### 6.6 "플랜 이행 체크" 기능을 넣지 않는 이유
- 현재 탭이 방문할 때마다 실제 상태를 자동 반영하고, 플랜 탭도 열 때마다 재계산되므로 별도 이행 체크 플로우가 불필요

### 6.7 마이 탭
- 은퇴 목표 조회/수정 (희망 은퇴 나이, 라이프스타일 프리셋, 노후생활 금액 플랜)
- 부부합산 연동 관리 (배우자 동의)
- 게이미피케이션: 준비 레벨, 퀘스트, 뱃지
- 기타 설정

### 6.8 게이미피케이션
레벨(준비율 기반), 뱃지(행동 기반), 퀘스트(프로필완성/저축미션/리스크이벤트)

### 6.9 상품/솔루션 연계
- 부족분 해결 옵션(연금 추가납입, 변액연금, 종신보험 연금전환 등)을 플랜 탭 하단 추천 영역에서 제안
- 자사 상품 가입은 인앱에서 즉시 처리돼 바로 인지 가능 — 외부 계좌 기반 항목보다 마이데이터 반영 속도가 빠르다는 게 차별점

아이디어 — 팀 회의
- 플랜 탭에서 상품/솔루션까지 제안하는 것이 법무적으로 문제없는지 검토 필요
- 부족분을 메우는 방법으로 "미래 소득을 늘리는" 방안(재취업, 부업 등)도 함께 제안 가능

## 7. 계산 로직 (개념)
| 항목 | 계산 방식 |
|---|---|
| 목표 | 노후 월생활비 + 희망 은퇴 나이. 은퇴생활기간은 희망 은퇴 나이 ~ 90세로 가정 |
| 현재 값 | 자기선언 없이 마이데이터로 확인된 실제 자산만 사용. 갭 = 목표 − 현재 |
| 현재 탭 준비율 | 목표 월생활비를 총자산으로 환산한 "필요 은퇴자금"과 현재 총자산을 비교 (환산 방식은 오픈 이슈) |
| 플랜 충족 여부 | (현재 탭 실제 자산 + 계획 항목별 기대 기여분) vs 목표. 열 때마다 재계산 |
| 연령별 소득(소득 계단 그래프) | 국민연금·퇴직연금(종신형)은 개시 연령부터 동일 금액. 금융자산은 보유 총액 ÷ 은퇴생활기간 균등분할 |
- 준비율(%)을 성공 가능성 지표로 함께 활용, 별도 확률 시뮬레이션은 없음
- 세금/건강보험료는 이번 계산에 반영하지 않음

## 12. 오픈 이슈
- 추천 상품/행동 항목별로 마이데이터 감지가 가능한지 실사 (연금보험/IRP/국민연금 추가납부는 감지 가능 추정, 주택연금 전환·자산 증여는 확인 필요)

- 90세보다 오래 생존할 경우의 리스크를 소득 계단 그래프 밖에서 어떻게 안내할지

- 국민연금 외에 고정(비편집) 처리해야 할 항목이 더 있는지 (예: DB형 퇴직연금)
- 목표 노후 월생활비를 총자산("필요 은퇴자금")으로 환산하는 계산식/가정 확정 (할인율, 은퇴기간 등)
- 현재 탭의 매월 변화 인사이트 피드 도입 여부 및 상세
- 플랜 탭 추천 모달의 "설정하기" 버튼 카피/UX — 실행 완료로 오인되지 않도록
- 세금/건강보험료 반영 여부
- 소득대체율 프레임 채택 여부
- 성공지표/KPI, 비기능요구사항, 일정 확정
